## Task 2: JDBC Test - insert primes into the DB

**Code** (`src/main/java/com/example/db/JdbcTest.java`):

```java
public class JdbcTest {
    static final String URL  = "jdbc:h2:./primedb;MODE=MySQL";
    static final String USER = "sa";
    static final String PASS = "";

    public static void main(String[] args) throws Exception {
        try (Connection con = DriverManager.getConnection(URL, USER, PASS)) {
            try (Statement st = con.createStatement()) {
                st.execute("CREATE TABLE IF NOT EXISTS primes (id INT AUTO_INCREMENT PRIMARY KEY, prime_value BIGINT UNIQUE)");
            }

            int inserted = 0;
            try (PreparedStatement ps = con.prepareStatement("INSERT INTO primes(prime_value) VALUES (?)")) {
                for (long n = 1; n <= 30; n++) {
                    if (PrimeUtil.isPrime(n)) {
                        try {
                            ps.setLong(1, n);
                            ps.executeUpdate();
                            inserted++;
                        } catch (SQLException dup) {
                            // already inserted on a previous run
                        }
                    }
                }
            }
            System.out.println("Inserted new primes: " + inserted);

            try (Statement st = con.createStatement();
                 ResultSet rs = st.executeQuery("SELECT id, prime_value FROM primes ORDER BY prime_value")) {
                System.out.println("ID | PRIME");
                while (rs.next()) {
                    System.out.println(rs.getInt("id") + "  | " + rs.getLong("prime_value"));
                }
            }
        }
    }
}
```

`PrimeUtil.java`:

```java
public static boolean isPrime(long n) {
    if (n < 2) return false;
    if (n % 2 == 0) return n == 2;
    for (long i = 3; i * i <= n; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}
```

## Task 4: Check primality from the browser using a Servlet

**Code** (`PrimeServlet.java`):

```java
@WebServlet("/prime")
public class PrimeServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();
        String s = req.getParameter("n");
        out.println("<html><body style='font-family:sans-serif'>");
        try {
            long n = Long.parseLong(s.trim());
            boolean p = PrimeUtil.isPrime(n);
            out.println("<h2>" + n + " is " + (p ? "a PRIME number ✅" : "NOT a prime number ❌") + "</h2>");
        } catch (Exception e) {
            out.println("<h2>Please give a valid integer, e.g. /prime?n=17</h2>");
        }
        out.println("<a href='index.html'>Back</a></body></html>");
    }
}
```

![Task 4](screenshots/task4.png)

**Commentary:** The servlet reads the `n` query parameter, checks it with `PrimeUtil.isPrime()`, and shows the result in the browser. `?n=17` gives "17 is a PRIME number".
